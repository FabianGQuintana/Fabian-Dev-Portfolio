# Registro de proyectos

Un repositorio aparece en el portafolio **si y solo si** existe un archivo suyo
en esta carpeta. Nada se publica automaticamente.

Agregar un proyecto = copiar `_template.ts`, completarlo, commit.

La plantilla y el tipo `ProjectEntry` se crean en la **Fase 5**, junto con la
capa de servicio de GitHub que enriquece cada entrada con stars, lenguajes y
fecha del ultimo commit.
